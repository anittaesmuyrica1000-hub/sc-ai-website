## 성능 (Lighthouse 모바일, 로컬 측정)

**Performance 35점** — FCP 2.8s · LCP 6.9s · TBT 2,310ms · Speed Index 9.4s · CLS 0.038(양호)

- LCP 요소는 히어로 `<h1>` — Pretendard 웹폰트(CDN) 대기가 병목.
- 렌더 차단 리소스 1.24s: Pretendard·Font Awesome CDN CSS.
- 스크립트 평가 3.0s, 미사용 JS 115KB(≈850ms) — Next 청크 + Font Awesome 전체 로드.
- 서드파티 블로킹: GTM 312ms.
- ※ 로컬 머신 측정 + 모바일 스로틀링이라 절대값은 보수적. CrUX 필드데이터는 트래픽 부족으로 아직 없음.

### 성능 개선 권고 (우선순위)

1. **Font Awesome 서브셋화** — 전체 CSS(cdnjs) 대신 실제 사용 아이콘만 SVG/서브셋으로. 렌더 차단·미사용 CSS 대부분 해소.
2. **Pretendard 로딩 최적화** — `font-display: swap` 확인 + 핵심 웨이트만 preload (LCP 개선 직결).
3. **og-image.png 압축** — 435KB → 300KB 이하.
4. **color-contrast 1건 수정** — 접근성 96→100.
