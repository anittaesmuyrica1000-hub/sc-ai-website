# 무료 신청 페이지 분리 — 구현 계획

> 작성일: 2026-06-04 · 상태: **계획만 (구현 전)**
> 목적: 현재 `index.html` 최종 CTA에 인라인으로 들어 있는 "무료 데모 신청" 폼을 **독립된 신청 페이지**로 분리한다.

---

## 1. 배경 / 현재 상태

- 사이트는 **단일 정적 파일** `index.html` 하나로 구성 (빌드 시스템 없음, CSS는 `<style>` 인라인 블록 하나).
- 신청 폼은 `8. FINAL CTA` 섹션(`<section class="final" id="final">`)에 들어 있고, `<form class="cta-form" onsubmit="return false">` 더미다 — **백엔드 제출 처리 없음**.
- 신청으로 유도하는 진입점(현재 전부 `#final` 앵커):
  - 헤더 nav: `서비스 문의`(L345), `무료 데모 신청` 버튼(L346)
  - DECLARATION 히어로 CTA: `무료 데모 신청`(L359)
  - FINAL CTA 섹션 내부 submit 버튼(L587)

## 2. 목표

1. 신청 폼을 별도 페이지(예: `apply.html`)로 분리해 **랜딩 → 신청**의 흐름을 명확히 한다.
2. 모든 CTA 진입점을 새 페이지로 연결한다.
3. 신청 페이지에 **입력 검증 + 제출 후 완료(thank-you) 상태**를 추가해, 더미 폼보다 실제 신청 흐름에 가깝게 만든다.
4. 기존 디자인 토큰(`:root` CSS 변수)·컴포넌트 스타일(`.btn`, `.wrap` 등)을 **그대로 재사용**해 비주얼 일관성을 유지한다.

## 3. 설계 결정 (Decisions)

| 항목 | 결정 | 이유 |
|---|---|---|
| 파일명 | `apply.html` (대안: `signup.html`) | 기존 정적 파일 컨벤션과 동일하게 루트에 단일 HTML 추가 |
| CSS 전략 | 새 페이지에 **인라인 `<style>`** 으로 디자인 토큰 + 필요한 컴포넌트만 복사 | 프로젝트 철학(외부 스타일시트 없음) 유지. 공유 `.css` 추출은 범위 확대라 이번엔 보류 |
| 헤더/푸터 | `index.html`의 헤더·푸터 마크업을 그대로 가져와 재사용 (로고 링크는 `index.html`로) | 네비게이션 일관성 |
| 기존 FINAL CTA 섹션 | 폼 제거 → **요약 + "무료 신청하기" 버튼**(→ `apply.html`)으로 교체 | 신청 흐름을 한 곳(신청 페이지)으로 단일화 |
| 제출 처리 | 1단계: 클라이언트 검증 + JS로 완료 화면 전환(여전히 비기능 백엔드). 2단계(후속): Supabase 테이블 또는 폼 서비스 연동 | 백엔드는 아직 없음 — 우선 UI/UX 확정 |
| 진입점 링크 | `#final` → `apply.html` 로 일괄 교체 | 새 페이지로 트래픽 유도 |

> ⚠️ 미해결 / 확인 필요: **실제 제출 데이터를 어디로 보낼지**(Supabase insert vs. 외부 폼 서비스 vs. 이메일). 1단계는 UI만, 백엔드 연동은 별도 후속 작업으로 둔다.

## 4. 신청 페이지 구성 (Sections)

1. **상단 헤더(nav)** — `index.html`과 동일. 로고 클릭 시 홈으로.
2. **신청 폼 메인** — 좌측 카피(왜 신청하는가 + 안심 요소), 우측 폼 카드. 모바일에서는 세로 스택.
   - 입력: 이름, 회사, 직무/직책(선택), 업무 이메일, 연락처(선택), 채용 규모(select), 문의 메모(textarea, 선택)
   - 체크박스: 개인정보 수집·이용 동의(필수)
   - 제출 버튼: `무료 신청하기`
3. **완료(Thank-you) 상태** — 제출 성공 시 폼 카드를 완료 메시지로 교체(체크 아이콘 + "신청이 접수되었습니다" + 다음 안내 + 홈으로 돌아가기).
4. **푸터** — `index.html`과 동일.

### 폼 필드 정의

| 필드 | 타입 | 필수 | 비고 |
|---|---|---|---|
| 이름 | text | ✅ | |
| 회사 | text | ✅ | |
| 직무/직책 | text | — | |
| 업무 이메일 | email | ✅ | 형식 검증 |
| 연락처 | tel | — | |
| 채용 규모 | select | ✅ | 1~10 / 11~50 / 51~200 / 200+ |
| 문의 메모 | textarea | — | |
| 개인정보 동의 | checkbox | ✅ | 미체크 시 제출 불가 |
