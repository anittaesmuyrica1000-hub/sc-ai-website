# 2026-06-09 · GNB 오버레이 마감 · 푸터 로고 · HOW 리포트 재구성 · 모바일 패딩

전날 시작한 GNB 스크롤 반응형과 로고 작업을 마무리하고, HOW 섹션의 리포트 영역을 Wise 식 2단/교차 레이아웃으로 재구성했다. 모바일 패딩 체계도 정리.

## GNB — 스크롤 반응형 마감
- 히어로 위 투명 → 스크롤 시 흰 배경+블러(`.scrolled` 토글), 슬라이드 등장.
- 다크 섹션 컬러 락업 ↔ 밝은 섹션 솔리드 반전.
- **모바일(≤560px) 로고 심볼-only**: `.logo overflow:hidden` + width 50px 클립(심볼 우측 48px < 워드마크 53px).

## 로고 / 푸터
- 로고를 공식 SVG로 교체(밝은 컬러 / 다크 흰색).
- 푸터 로고를 회색 SVG(supercoder-nav-gray.svg)로 적용, opacity 70%로 톤 정리.

## HOW IT WORKS — 리포트 재구성 (Wise 식)
- 단일 이미지 → **이미지(좌) + 정보(우) 2단** → 좌우 교차 3행(텍스트+이미지 박스)으로 재구성.
- 보고서 섹션 이미지 삽입, 4:3(512×384) 동일 크기 통일.
- '단 3단계' 인트로 상단 패딩 추가로 위 3행과 여유 확보.

## FLOOD / ROLE
- FLOOD(≥881px): 헤드·통계 수평·수직 중앙 정렬, 헤드/서브 카피 교체, 좌우 간격 여유.
- ROLE(역할 분담) 섹션 상·하단 패딩 확대(우측 깔때기 답답함 해소), 좌 카피·우 깔때기 수직 중앙 정렬.
- ROLE 깔때기 확대(좁은 데스크톱 1.2 / ≥1180px 1.42)로 가독성↑.

## PROOF / VOICES / FINAL CTA
- PROOF 카피 전환 강조형으로 교체('AI 면접 하나로, 1차 검토가 이렇게 바뀝니다').
- VOICES 배경 `#fff`로 변경(앞 PROOF 연블루와 경계 구분).
- **FINAL CTA**: 풀블리드 → inset 둥근 사각형 카드(Wise 스타일) + 카피 교체.

## 모바일
- 모바일 패딩을 Wise 식으로 조정(거터 16px·섹션 48px).
- 히어로 모바일 화면 정중앙 배치(min-height 100svh).
