# 2026-06-05 · 섹션 디자인 집중 반복

가장 많은 작업이 이뤄진 날(80 commit). 로고를 공식 벡터 SVG로 교체하고, 거의 모든 섹션의 레이아웃·타이포·여백을 반복 조정했다. 섹션 체계도 이날 정의했다.

## 로고 / 기반
- 래스터 로고 → **공식 브랜드 가이드 벡터 SVG**로 교체.
- 전역 `word-break:keep-all` — 한국어 줄바꿈을 어절 단위로(글자 깨짐 방지).
- **섹션 체계 정의** + 섹션 헤드/서브카피 타이포 통일(행간 130%).

## 히어로(DECLARATION)
- 헤드카피 타이포 스펙 적용(Pretendard ExtraBold 56/130%/-1%) + 반응형.
- 헤드카피 문구: "1차 검토는 AI 코비에게, 채용팀은 진짜 인재만 만나세요"('AI 코비' 강조).
- **도트 지구본(hero-globe.png)** 배경 도입 → 위치·크기·투명도·마스크 반복 조정.
- 지구본 모션 실험: 플로팅 → 360도 회전 → 유기적 맥동(심장박동+호흡 글로우) → 최종 360도 회전 복귀. `prefers-reduced-motion` 존중.
- 도입사 로고를 한 줄 무한 루핑 마퀴로 변경.

## FLOOD(채용의 현실)
- 풀폭 4카드 → 좌 헤드 + 우 통계(비대칭) → 전체 중앙 정렬로 재설계.
- 통계 리스트를 흰색 카드 박스로 감싸고, 행간·박스 폭(560→460px)·여백 정비.
- 헤드라인 위 '채용의 현실' 태그칩 추가, 배경 `var(--soft)`.

## ROLE REVERSAL(역할 분담) — 깔때기
- 첨부 디자인대로 **SVG 깔때기 재구현** → 전체 역삼각형으로 재구성.
- 세그먼트 그라데이션·점선 가이드·AI/채용팀 칩 정렬 반복 조정.
- 단계별 지원자 수(5,000→800→40→10명) 점선 시각화 추가, 모바일 대응.
- 태그칩 '해결' → '역할 분담'.

## VALUE(솔루션)
- 원형 교집합(벤) 시안 제거 → **화이트 카드 레이아웃 확정**.
- 카드 아이콘 배경 제거(글리프만 블루), 설명 2줄 요약, 메트릭 뱃지 하단 정렬.
- 3개 요소를 모든 폭에서 한 줄(3열) 유지.

## HOW IT WORKS
- 데모 이미지를 **실제 AI 면접 리포트 화면**으로 교체, 사각 프레임 제거(drop-shadow만).
- 3단계 플로우 카드 간격·설명 줄수·반응형 정리, STEP 아이콘 배경 제거.

## PROOF / VOICES
- 도입 효과 3지표를 모든 폭에서 한 줄(3열) 유지, 배경 `#F4F8FF` 통일.
