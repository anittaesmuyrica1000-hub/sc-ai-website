# 2026-06-08 · 다크 히어로 · 입자 모션 · GNB 반응형 · 수치 정성화

히어로/CTA를 다크 톤 + 발광 입자 모션으로 전환하고, GNB를 스크롤·섹션 인지형으로 만들고, 로고를 공식 SVG로 정비했다. 근거 없는 수치를 제품 사실 기반으로 교체한 카피 작업도 진행.

## 히어로 / CTA — 다크 + 입자 모션
- 히어로를 **다크 버전**으로 적용: 다크 그라데이션 + 중앙 글로우, 발광 입자, 흰 헤드라인.
- 다크 히어로 미리보기(hero-dark-preview.html) 선행 후 본 적용.
- 서브카피 가독성 수정(`.decl p` 밝은 슬레이트 `#AEB9D4`).
- **입자 수렴 모션**: 화이트 점이 '진짜 인재만'으로 수렴, 스크립트 공용화.
- 입자 색 팔레트(청록·하늘·파랑·보라 4색), 불투명도 조정.
- **성능 최적화**: IntersectionObserver로 화면에 보일 때만 애니메이션(히어로/CTA 공통).
- CTA를 히어로와 동일 룩으로 통일(다크+글로우, btn-blue).
- 강조어 그라데이션 반복 조정 → 로고 색 계열로 수렴, '진짜'만(조사 포함) 강조.

## GNB — 스크롤 / 섹션 인지형
- GNB를 다크 히어로 위에 오버레이: 투명 → 스크롤 시 솔리드(`.scrolled` 토글, 블러).
- **섹션 인지형 색상(Notion 식)**: 다크 섹션 위 반전 / 밝은 섹션 위 솔리드.
- 다크 섹션에서 컬러 락업(supercoder-nav-color.png)으로 교체.
- 히어로 최상단 숨김 → 스크롤 시 흰 GNB 슬라이드 등장.

## 로고
- 로고를 **공식 SVG**로 교체(밝은 배경 컬러 / 다크 배경 흰색).
- 푸터 로고를 회색 SVG로 적용 + 투명도(opacity .5~.7) 조정.

## 카피 — 수치 정성화 (근거 없는 숫자 제거)
- VALUE 카드: 60%↓/94% 같은 무근거 수치 → '1차 검토 시간↓', '핵심 역량 검증 정확도↑'.
- VALUE 헤드라인: 'AI가 먼저 검증' → 'AI 면접이 먼저 검증', 카드 제목 '속도'→'빠른 속도'.
- PROOF: 무근거 40%·94% 제거 → 제품 사실 숫자(검증 범위 100%·리포트 3단계).
- PROOF를 VALUE 순서(속도/비용절감/검증)로 정렬 + **출처 있는 데이터**(1,272만원·출처 사람인) 적용.

## ROLE 깔때기 / FLOOD
- ROLE 깔때기를 헤드카피보다 아래로(margin-top 104px), 그래프 확대(scale 1.16, 우측 기준).
- '최종 판단' 삼각형·'채용팀' 그룹 색을 GNB 로고 진한 남색 `#2144a5`로 통일.
- FLOOD 통계 박스 위치(margin-top 104px)·폭·패딩 조정.
