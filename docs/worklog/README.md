# 작업 로그 (Worklog)

Supercoder AI 웹사이트(**AIVIEW** 랜딩) 작업 내역을 **날짜별 문서**로 정리한다.
각 문서는 그날의 commit을 주제별로 묶어 요약한 것이며, 상세 변경은 `git log`를 참조한다.

## 작성 규칙

- 파일명: `YYYY-MM-DD.md` (작업한 날짜 기준)
- 한 날짜 = 한 문서. 그날 작업을 **주제(섹션·기능)별**로 묶어 정리한다.
- 새로 작업한 날에는 이 폴더에 해당 날짜 문서를 추가하고, 아래 인덱스에 한 줄 추가한다.
- 카피·식별자·커밋 메시지 원문은 그대로 두고, 설명은 한국어로 작성한다.
