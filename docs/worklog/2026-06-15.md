# 2026-06-15 · SEO 전면 구축 · 약관/개인정보 · 도메인 확정 · 블로그 · Next.js 전환

배포·운영을 위한 SEO 기반과 법무 문서를 갖추고, 운영 도메인을 확정했다. 이어 블로그(리스트·상세·어드민) 기능을 추가하고, **정적 HTML에서 Next.js(App Router) web app으로 전환**했다. GNB에는 소개서 다운로드 CTA를 붙였다.

## SEO 기반 구축
- 메타데이터·OG·구조화 데이터·robots·sitemap·favicon 추가.
- 이미지 WebP 전환, 404 페이지, FAQ 섹션 추가, SEO 체크리스트 완료.
- Google Search Console 소유확인 메타태그 추가(index.html head).
- 파비콘 잘림 수정(viewBox가 심볼 우측 x>40을 클리핑하던 문제 해결).

## 운영 도메인 확정 / 배포
- 운영 도메인 **sc-ai-website.vercel.app** 확정 → 플레이스홀더 일괄 치환, robots·sitemap 주석에 확정일 명시.
- 배포·도메인 확정·플레이스홀더 치환 완료 체크리스트 반영.
