2. 본문은 네 가지 규칙만

  1. 기능은 번호를 붙여 한 줄 제목으로. 1. 면접 언어 5개 추가 처럼 쓰시면 됩니다. 번호가 중간에 어긋나도 자동으로 다시 매깁니다.
  2. 나열은 - 항목 — 설명 형태로. 항목과 설명 사이는 긴 줄표(—)나 쌍점(:)으로 나눠 주세요. 이런 줄이 3개 이상 이어지면 표로, 그보다 적으면 목록으로 나갑니다.
  3. 설명만 있는 나열은 그냥 - 내용 으로 쓰시면 목록이 됩니다.
  4. 회사별 설정이 필요한 기능은 제목 끝에 (옵션 · 별도 설정 필요) 를 붙여 주세요.
