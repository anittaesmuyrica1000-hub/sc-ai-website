# 작업 기록 — 2026-08-03

## 1. 어드민 업데이트 미리보기 표 스타일 수정

**문제:** 어드민(`/admin`) 업데이트 글 수정 화면에서 "미리보기" 버튼 클릭 시 표(table)가 깨져 보임.

**원인 (3가지 복합):**
1. `app/admin/page.tsx`에 `update.css` import 누락 → `.upd-content .post-table` 규칙 자체가 어드민에서 로드되지 않음
2. RichEditor(contentEditable 기반)가 표를 삽입할 때 `class="post-table"` 없이 bare `<table>`만 생성 → CSS 선택자 불일치
3. `border-collapse:collapse`와 `border-radius`는 CSS상 공존 불가 → 래퍼 div 없이 둥근 모서리 구현 불가

**수정 내용:**

| 파일 | 변경 내용 |
|------|----------|
| `app/admin/page.tsx` | `import "../update/update.css"` 추가 |
| `lib/postRender.ts` | `renderBody()`에 bare `<table>` → `<div class="post-table-wrap"><table class="post-table">` 정규식 변환 추가 |
| `app/update/update.css` | 임시 추가했던 plain table 폴백 CSS 제거 (renderBody 정규식으로 대체) |

**결과:** 미리보기 모달에서 표 헤더 배경·행 구분선·둥근 모서리(border-radius:12px) 모두 정상 적용 확인.

**왜 앞으로는 재발하지 않는가:**
- 그리드 픽커로 표 삽입 시: `insertTable()`이 처음부터 `class="post-table"` + `post-table-wrap` 포함 HTML 생성
- 외부 붙여넣기 또는 기존 DB 콘텐츠: `renderBody()`가 렌더링 시 자동 정규화
- `admin/page.tsx`의 `update.css` import는 영구 적용
