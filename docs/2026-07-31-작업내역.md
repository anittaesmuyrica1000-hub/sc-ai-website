## 2. 렌더링 버그 수정 (코드)

### 문제
개인정보처리방침 신규 본문에 `<br>` 태그가 포함된 마크다운 표가 있어, `looksHtml=true`로 판별 → 마크다운 렌더링이 통째로 건너뛰어짐. 결과적으로 `**굵게**`, `## 제목` 등이 화면에 그대로 노출.

### 원인
`lib/postRender.ts`의 `looksHtml` 판별 정규식에 `<br>` 포함.

### 수정 내용 (`lib/postRender.ts`)
- `looksHtml` 정규식에서 `br` 제외
- `inline()` 함수: `<br>` 태그 기준으로 split → 각 파트 이스케이프 후 rejoin → `<br>` 보존

```ts
// before
const looksHtml = /<(p|h[1-6]|...|br)\b/i.test(body);

// after
const looksHtml = /<(p|h[1-6]|ul|ol|li|div|table|tr|td|strong|em|b|i|u|a|img|blockquote|hr|figure)\b/i.test(body);

function inline(s: string): string {
  return s.split(/(<br\s*\/?>)/gi).map((part, i) => {
    if (i % 2 === 1) return "<br>";
    // ... esc + 마크다운 치환
  }).join("");
}
```
