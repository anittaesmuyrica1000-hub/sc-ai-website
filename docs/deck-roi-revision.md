## 0. 핵심 발견 — 덱 수치는 "근거 없음"이 아니라 "자체 설문을 부풀림"

덱 p14의 ROI는 **슈퍼코더 자체 고객 설문**에서 나온 것이며, 언론 보도까지 있다.

- **조사:** 슈퍼코더 × 동서남북(홍보법인), **파트너사 인사담당 267명** 온라인 설문, 조사기간 **2024.1~2025.1**, 2025.1 발표.
- **보도:** 서울경제 「AI 면접관 도입 기업 10곳 중 6곳 "채용 기간·비용 줄여"」 (sedaily.com/article/20022775)

**설문 원문 수치(정확):**
| 항목 | 설문 결과 |
|---|---|
| 채용 기간 | 평균 **44일 → 21일** |
| 채용 기간·비용 절감폭 | **"절반 이상 절감" 62%** / 30~50% 절감 12% / 10~30% 절감 23% / 10%미만 3% |
| 최종 인터뷰 합격률 상승 | **50%p 이상 ↑ 48%** / 30~50%p 34% / 10~30%p 11% / 10%미만 7% |

**그런데 덱은 이 설문보다 수치를 키워 적었다 — 이게 진짜 리스크:**
| 덱 p14 표기 | 자체 설문 실제값 | 문제 |
|---|---|---|
| 채용 기간 단축 **65–70%** (44일→**10–15일**) | 44일→**21일** (≈ **52%**) | 종료일·절감률 모두 부풀림. 자기 설문과도 불일치 |
| 채용 비용 절감 **60–65%** (500만→1–200만원) | "절반 이상 절감 **62%**"(기업 비율) | "62%의 기업이 절반 이상 절감"을 "62% 절감"으로 오독 유발. 500만/200만 baseline은 출처 없음 |
| 인터뷰 합격률 **2배**(10–30%→40–60%) | "50%p 이상 ↑가 응답의 48%" | 전수 평균이 아니라 응답 분포. "2배" 단정 근거 없음 |

→ **결론: 대기업 구매팀은 "벤더 자체 설문(n=267, self-report)"임을 즉시 간파한다.** 자체 설문을 ① 출처·표본·기간 명시하고 ② 설문 결과와 정확히 일치시키면 신뢰가 살고, 지금처럼 부풀리면 전체 덱의 신뢰가 무너진다.

## 1. 대체 원칙 — "고통은 중립 데이터로, 성과는 정직한 자체 설문으로"

ROI 슬라이드를 **2층 구조**로 재설계한다.

- **(A) Before / 현황(고통의 크기) = 중립 3자 국내 통계.** 사람인·잡코리아·고용노동부. 벤더 이해관계 0 → 반박 불가.
- **(B) After / 개선폭 = 슈퍼코더 자체 설문, 단 출처·표본·기간 병기 + 설문값과 정확히 일치.** "도입 파트너사 267곳 설문 기준"임을 숨기지 말고 **밝혀서** 정직성으로 신뢰를 얻는다.

핵심: **퍼센트를 "제품이 보장하는 효과"처럼 단정하지 말고, "도입 기업이 응답한 결과"로 프레이밍**한다.

## 2. 항목별 대체 매핑 (p14)

### ① 채용 기간 단축
- **덱 현재:** `65–70% (기존 평균 44일 → 10–15일)` ❌
- **대체안:**
  - (A·중립) "국내 기업은 직원 1명 채용에 평균 **32일** 소요" <sub>사람인 499개사, 2022</sub>
  - (B·자체) "AIVIEW 도입 파트너사는 채용 기간이 **평균 44→21일**로 단축" <sub>슈퍼코더·동서남북, 도입사 인사담당 267명 설문, 2024.1~2025.1</sub>
- **카피:** 「채용 기간 **44일 → 21일**」 + 작은 글씨 출처. (65–70%·10–15일 삭제)

### ② 채용 비용 절감
- **덱 현재:** `60–65% (500만 → 1~200만원)` ❌ (baseline 500만원 출처 없음)
- **대체안:**
  - (A·중립) "채용 1인당 평균 **1,272만원**" <sub>사람인 499개사, 2022</sub> + "신입 **28.7%**가 1년 내 조기퇴사 → 재채용 비용 반복" <sub>사람인 1,124개사, 2022</sub>
  - (B·자체) "도입 파트너사 **62%가 채용 기간·비용을 '절반 이상' 절감**했다고 응답" <sub>슈퍼코더 설문, 267명</sub>
- **카피:** 「도입 기업 **62%**가 채용 비용 **절반 이상 절감**」 + "채용 1인당 1,272만원(사람인)" 보조. (단일 "60–65%" 삭제 — "62% 기업"과 혼동되므로)

### ③ 인터뷰 합격률 향상
- **덱 현재:** `2배 (기존 10–30% → AI 평가 후 40–60%)` ❌
- **재해석:** 이 지표는 "1차 스크리닝이 걸러줘서 **최종 면접에 올라온 후보의 질이 높아졌다**"는 뜻. "합격률 2배"보다 **"면접 효율"**로 프레이밍이 정확.
- **대체안:**
  - (B·자체) "도입 파트너사 **48%가 최종 인터뷰 합격률이 50%p 이상 상승**" <sub>슈퍼코더 설문, 267명</sub>
- **카피:** 「검증된 후보만 올라와, **최종 면접 합격률 ↑** — 도입 기업 48%가 50%p 이상 상승」. ("2배" 삭제)

### (선택) 신뢰 보강용 중립 앵커 한 줄
ROI 슬라이드 하단에 "**우리가 푸는 고통**"을 중립 수치로:
> "신입 조기퇴사로 **1인당 2,000만원+ 손실**을 본다는 기업이 75.6%" <sub>고용노동부·고용정보원 315개사, 2023</sub>

## 3. 사용 사례 성과 수치 (p16~18) 처리

이 수치들(70%·3배·95%)은 자체 설문에도 없는 **개별 시나리오 추정**일 가능성이 높다. 검증 불가 시 다음 중 택1:

| 슬라이드 | 덱 수치 | 권고 |
|---|---|---|
| #1 개발자 — "스크리닝 생성 속도 70% 향상" | 70% | 출처 확인 불가 시 → 정성 표현("대규모 기술 스크리닝을 자동화") + 중립 앵커("개발 직군 경쟁률 1년 새 55%↑, 잡코리아 2025")로 교체 |
| #2 고객서비스 — "채용 속도 3배" | 3배 | 동일. "반복 인터뷰를 24/7 자동화"로 정성화하거나, 설문값(44→21일)으로 통일 |
| #3 캠퍼스/신입 — "초기 스크리닝 95% 단축" | 95% | "수동 평가 불가능한 대규모"라는 **정성 메시지**가 더 강함. 95%는 산정식 없으면 "사람 수동 대비 추산"으로 명시하거나 삭제 |

원칙: **검증 가능한 수치가 없으면 정성 메시지 + 중립 고통 통계로 대체**한다. 근거 없는 큰 숫자 하나가 덱 전체 신뢰를 깎는다.

## 5. 인용 절대 주의

- 자체 설문은 **반드시 "도입 파트너사/도입 기업 설문, n=267, 2024.1~2025.1"** 병기. "업계 평균"으로 표기 금지(self-selection 편향).
- "62%"는 **절감률이 아니라 "절반 이상 절감한 기업 비율"**. "62% 절감"으로 쓰면 오인용.
- "50%p↑ 48%"는 전수 평균 아님 → "응답 기업의 48%"로 표기.
- 중립 통계(32일·1,272만원·28.7%)는 모두 **2022 기준** → "현재/최신" 단정 금지.
- 사용 사례 70%·3배·95%는 산정식 확보 전 단정 인용 금지(§3).
