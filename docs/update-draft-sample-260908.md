개요
이번에는 해외 채용이랑 면접 일정 운영 쪽에 힘을 많이 줬습니다.
면접과 리포트를 5개 언어로 더 지원하고, 면접 마감을 날짜가 아니라 시각까지 정할 수 있게 했습니다.

주요 업데이트

1. 면접 언어 5개 추가
기존 한국어, 영어, 아랍어에 일본어, 중국어(간체), 프랑스어, 스페인어, 독일어를 추가했습니다.
- 질문 생성 — 선택한 언어로 면접 질문이 생성됩니다
- 면접 진행 — 안내 음성과 질문이 선택한 언어로 전달됩니다
- 인재상 면접 — 인재상 면접도 같은 언어로 진행됩니다

2. 리포트 언어 별도 선택
프로젝트를 만들 때 면접 언어와 리포트 언어를 따로 고를 수 있습니다.
- 현지 언어로 면접을 보고, 리포트는 채용팀이 읽는 언어로 받습니다

3. 면접 마감 시각 정식 적용
면접 일정을 날짜가 아니라 날짜와 시간으로 지정합니다.
- 지정 시점 — 면접 시작, 시작 마감, 면접 마감 세 시점을 지정합니다
- 마감 후 동작 — 마감 시각이 지나면 신규 시작과 재시작이 차단됩니다
- 진행 중인 면접 — 마감 시각이 지나도 중단되지 않고 끝까지 진행됩니다

4. 인재상 기반 면접 개선 (옵션 · 별도 설정 필요)
인재상 면접의 질문 구성 방식을 다듬었습니다.
- 추천 질문 수 — 항목당 추천 질문을 2문에서 1문으로 정리했습니다
- 질문 카드 — 질문마다 교체, 수정, 삭제를 지원합니다
- 질문 교체 — 교체 시 검증된 질문 뱅크에서 대안을 제시합니다

운영 경험 개선
- 면접 진행 안정성 — 음성 인식 서버의 일시적 오류를 재시도해 답변 유실 가능성을 줄였습니다
- 제출 안내 — 답변 후 5초간 조용하면 제출 버튼 안내 문구가 표시됩니다

버그 수정
- 질문 자막 — 자막이 표시 도중 사라졌다 다시 나타나던 문제 수정
- 마지막 질문 — 마지막 질문에서 재질문을 요청하면 면접이 종료되던 문제 수정
- 초대 이메일 — 초대 이메일에 삽입한 이미지가 깨지던 문제 수정
- 인재상 리포트 — 인재상 리포트 생성이 실패하던 문제 수정

보안 및 안정성
- 보안 업데이트 — 서버와 프론트엔드 구성 요소에 보안 업데이트를 적용했습니다
- 동시 사용 안정성 — 대규모 동시 사용 환경에서의 안정성을 강화했습니다

이용 안내
- 면접 마감 시각 — 날짜 기준으로 운영하시던 프로젝트는 마감 시각을 한 번 확인해 주세요
- 추가된 언어 — 별도 설정 없이 프로젝트 생성 시 바로 사용하실 수 있습니다
- 옵션 기능 — 인재상 기반 면접은 기본값이 비활성이며 회사별 설정이 필요합니다

마무리
이번 업데이트로 더 많은 언어의 지원자를 같은 기준으로 평가하고, 면접 일정을 의도한 대로 운영할 수 있게 되었습니다.
앞으로도 지원자와 채용팀 모두 면접 자체에만 집중할 수 있도록 다듬어 나가겠습니다.
